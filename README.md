# The Iceberg of Money Laundering

An interactive, illustrated long-read on the hidden architecture of money laundering, a guided descent from a €1.80 phishing text down to the banks that stopped being banks.

**Live:** https://ShellPayant.github.io/iceberg-of-money-laundering/

## About

A single, self-contained HTML file — no build step, no dependencies, no tracking. Open `index.html` locally or host it on any static host.

- Scroll-driven descent with a live depth gauge, pinned diagrams, and full-bleed animated vector plates
- 28 sourced footnotes and a hidden "field guide" methods layer
- Respects `prefers-reduced-motion`; degrades gracefully on mobile

## Files

- `index.html` — the essay (everything is inlined)
- `share.png` — social preview card
